# Portfolio – Echakhse Mounir

Portfolio personnel réalisé avec React et Vite afin de présenter mon parcours, mes compétences et les principaux projets réalisés durant ma formation de développeur web.

Installation

1. Cloner le dépôt
git clone https://github.com/Mounir-e/P12_Portfolio.git

2. Accéder au dossier du projet
cd P12_PORTFOLIO

3. Installer les dépendances
npm install

4. Lancer le serveur de développement
npm run dev

http://localhost:5173
Ouvrez cette adresse dans votre navigateur.
